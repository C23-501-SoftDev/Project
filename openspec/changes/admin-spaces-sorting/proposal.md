## Why

Текущая таблица пространств в админ-панели отображает данные в обратном порядке по умолчанию, а заголовки столбцов не управляют сортировкой. Это ухудшает навигацию по списку и делает поведение таблицы менее предсказуемым для администратора.

## What Changes

- Добавить управляемую сортировку для страницы `/admin/spaces` по всем колонкам, кроме `Actions`.
- Сделать заголовки таблицы кликабельными и переключать направление сортировки при повторном клике.
- Изменить порядок по умолчанию на естественный (`asc`) вместо обратного.
- Пробросить параметры сортировки в `/api/admin/spaces`.

## Capabilities

### New Capabilities
- `admin-panel-ui`: Таблица пространств с кликабельными заголовками и сортировкой по выбранному столбцу.

### Modified Capabilities
- `space-management`: Расширение административного списка пространств параметрами сортировки.

## Impact

- **API**: `GET /api/admin/spaces` получает параметры `sortBy` и `sortDir`.
- **UI**: `admin-spaces.html` добавляет кликабельные заголовки и состояние сортировки.

- **Feature ID**: `admin-panel-ui`
