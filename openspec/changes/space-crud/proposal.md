## Why

Реализация полноценного CRUD для сущности `Space` необходима для административного управления разделами базы знаний. Текущая реализация `spaces-and-permissions` предоставляет лишь базовую инфраструктуру, в то время как полноценное управление (редактирование, удаление, смена владельца) критично для поддержания актуальности структуры системы.

## What Changes

- Добавление эндпоинта для получения детальной информации о пространстве по ID.
- Добавление эндпоинта для обновления данных пространства (имя, описание, владелец).
- Добавление эндпоинта для удаления пространства.
- Реализация бизнес-логики смены владельца и каскадного удаления связанных ресурсов.
- Обеспечение консистентности `updatedAt` при изменениях.

## Capabilities

### New Capabilities
- `space-crud`: Полный набор операций управления пространствами для администраторов, включая валидацию уникальности имен и автоматическое управление правами OWNER.

### Modified Capabilities
- `space-management`: Расширение существующих требований к управлению пространствами (добавление Update/Delete операций).

## Impact

- **API**: Новые эндпоинты в `SpaceController` под префиксом `/api/admin/spaces`.
- **Domain**: Обновление сущности `Space` и интерфейса `SpaceRepository`.
- **Application**: Расширение `SpaceService` логикой обновления и удаления.
- **Infrastructure**: Реализация новых методов в `SpaceRepositoryImpl` и `SpaceJpaRepository`.
- **Docs**: Ссылка на [US4.2.1 CRUD сущности Space](../../../Docs/documents/backlog-descriptions/E4%20Администрирование%20и%20Безопасность%20(Admin%20&%20Security)/F4.2%20Управление%20Пространствами/US4.2.1%20CRUD%20сущности%20Space/description.md).
