## ADDED Requirements

### Requirement: Attachment Entity Management
Система ДОЛЖНА поддерживать прикрепление файлов к документу с хранением метаданных в БД и физического файла в blob-хранилище.

#### Scenario: Successful upload
- **WHEN** пользователь редактирует документ и отправляет файл через drag-and-drop или кнопку выбора файла
- **THEN** система сохраняет файл в целевой blob/SMB-директории
- **AND** записывает метаданные вложения в БД
- **AND** связывает вложение с документом

#### Scenario: Attachment deletion
- **WHEN** пользователь удаляет прикреплённый файл
- **THEN** система удаляет физический файл из blob/SMB-хранилища
- **AND** удаляет запись метаданных из БД
- **AND** вложение больше не отображается в документе

#### Scenario: File size validation
- **WHEN** пользователь пытается загрузить файл больше допустимого размера
- **THEN** система отклоняет загрузку
- **AND** возвращает понятное сообщение с максимальным допустимым размером

#### Scenario: File type validation
- **WHEN** пользователь пытается загрузить файл с запрещённым расширением
- **THEN** система отклоняет загрузку
- **AND** возвращает сообщение со списком допустимых типов файлов
