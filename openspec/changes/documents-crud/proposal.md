## Why

Пользователям необходим механизм для управления текстовым контентом (документами) в Базе знаний. Текущая реализация требует базовых операций создания, чтения, обновления и удаления (CRUD) с интеграцией Git для хранения содержимого и поддержки жизненного цикла документа.

FeatureId: `documents-crud` (from `openspec/feature-registry.json`)

## What Changes

- Реализация REST API для управления документами (CRUD).
- Интеграция с Git (через JGit) для хранения тела документа (`.md` файлов).
- Поддержка метаданных документа в PostgreSQL (заголовок, автор, пространство, статус).
- Обеспечение базового жизненного цикла (статус `Draft` при создании).

## Capabilities

### New Capabilities
- `documents-crud`: Базовые операции над документами, включая сохранение метаданных в БД и контента в Git.

### Modified Capabilities
- `spaces-and-permissions`: (Опционально) проверка прав доступа к пространствам при создании документов в них.

## Impact

- **Backend**: Новые сущности `Document`, контроллеры, сервисы и инфраструктурный слой для JGit.
- **Database**: Новая таблица `documents` (Liquibase миграции).
- **FileSystem/Git**: Создание и обновление файлов в локальном Git-репозитории.
- **API**: Новые эндпоинты `/api/documents/**`.
