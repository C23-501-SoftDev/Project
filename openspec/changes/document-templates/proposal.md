Пользователям требуется возможность использовать готовые шаблоны документов для ускорения работы и поддержания единого стиля документации в системе, а также автоматически присваивать уникальные номера требованиям внутри документов, созданных из шаблонов.

## What Changes

- Добавление системы шаблонов документации.
- Реализация API для получения списка доступных шаблонов (`getAvailableTemplates()`).
- Хранение шаблонов в БД с метаданными (специализация).
- Отображение списка шаблонов в интерфейсе создания документа (при наличии права `canWrite`).
- Обеспечение возможности создания документа на основе выбранного шаблона, после чего документ становится независимым.
- Автоматическая генерация уникальных номеров требований в формате `REQ-XXX` для документов, созданных из шаблонов.

## Capabilities

### New Capabilities
- `document-templates`: Поддержка шаблонов документов, включая API и логику выбора/создания на основе шаблона.

### Modified Capabilities
- `documents-crud`: Требуется расширение для интеграции выбора шаблона при создании нового документа.

## Impact

- Новая таблица в БД для хранения шаблонов.
- Новый эндпоинт `GET /api/templates`.
- Обновление интерфейса создания документов в UI.
- Обновление логики сервиса создания документов в `application` слое для поддержки создания из шаблона.
- Добавление постоянного хранилища счетчиков требований в PostgreSQL.
