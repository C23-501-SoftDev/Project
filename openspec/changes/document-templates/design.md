## Context

Внедрение системы шаблонов для документов для ускорения их создания и обеспечения единства оформления. Реализация в рамках архитектуры Spring Boot / JPA / PostgreSQL.

## Goals / Non-Goals

**Goals:**
- Создание JPA сущности `Template`.
- Реализация сервисного слоя для получения списка доступных шаблонов.
- Интеграция выбора шаблона в UI создания документа.
- Обеспечение независимости созданного документа от шаблона.

**Non-Goals:**
- Сложная система управления правами на сами шаблоны (доступны всем авторизованным).
- Редактирование шаблонов через UI (предзагрузка шаблонов в систему).

## Decisions

- **Сущность Template**: Хранение в БД в таблице `templates` (название, контент, специализация).
- **API**: Новый эндпоинт `GET /api/templates`.
- **UI**: Выбор шаблона при создании нового документа. При выборе шаблона контент нового документа инициализируется контентом шаблона.
- **Интеграция**: При создании документа через контроллер `DocumentController` добавить опциональный параметр `templateId`.

## Risks / Trade-offs

- [Risk] Разрастание объема БД при большом количестве шаблонов → Митигация: шаблонов ожидается немного.
- [Risk] Дублирование логики инициализации документа → Митигация: выделить логику в отдельный метод сервиса.
