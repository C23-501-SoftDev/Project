## Why

Реализация функционала выбора и использования шаблонов документов для ускорения работы пользователей.

## What Changes

- Создание сервиса и API для получения списка шаблонов.
- Обновление логики создания документа для учета выбранного шаблона.
- Обновление UI для отображения шаблонов и инициализации контента документа.

## Capabilities

### New Capabilities
- `document-templates`: Поддержка шаблонов документов (API для получения списка, создание документа на основе шаблона).

### Modified Capabilities
- `documents-crud`: Интеграция выбора шаблона при создании нового документа.

## Impact

- Добавление API `GET /api/templates`.
- Обновление `DocumentService.createDocument` для инициализации из шаблона.
- Обновление UI создания документа.
- Использование существующих таблиц шаблонов (миграция 004 была выполнена).
