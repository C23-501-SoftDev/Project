# URL-параметры для фильтров

## Что

Реализовать полноценную поддержку URL-параметров для всех активных фильтров списка документов (пространство, автор, статус, сортировка, поиск) и обеспечить их сохранение при навигации через дерево пространств, а также восстанавливать состояние фильтров из URL при загрузке страницы.

## Почему

1. **Делимость ссылками** — пользователи могут отправлять ссылки с активными фильтрами друг другу (например, "все документы в статусе Draft в пространстве X").
2. **Кнопка "Назад" в браузере** — после перехода по ссылке из дерева пространств, параметры фильтрации сохраняются, что улучшает UX.
3. **Согласованность UI** — при загрузке страницы или перезагрузке состояние фильтров восстанавливается из URL, а не сбрасывается к значениям по умолчанию.
4. **Синхронизация кастомных селектов** — выбранное значение в кастомном выпадающем списке (пространства, авторы) корректно отображается после восстановления из URL или выбора через дерево.

## Область изменений

- **Только клиентский JavaScript** (Thymeleaf-шаблон `document-list.html`)
- **Только один файл:** `backend/src/main/resources/templates/pages/document-list.html`
- Никаких изменений в backend, API, базе данных или серверной логике

## Затрагиваемые функции

- Функция `updateUrl()` — теперь сериализует все фильтры в URL (authorId, status, sortBy, sortDir)
- Функция `applyFilters()` — вызывает `updateUrl()` после применения фильтров
- Функция `clearFilters()` — вызывает `updateUrl()` после очистки
- Обработчик `spaceSelected` — синхронизирует кастомный селект с выбранным пространством
- Обработчик `DOMContentLoaded` — полностью переработан: асинхронная загрузка опций, восстановление всех параметров из URL, синхронизация UI
- `toggleSpaceTree()` — сохраняет существующие URL-параметры при переходе на главную страницу

## Состояние до / после

**До:** URL содержал только параметры `page`, `spaceId`, `q`. После применения фильтров URL не обновлялся. При загрузке страницы не восстанавливались `sortBy`, `sortDir`, `status` как массив. Кастомные селекты не синхронизировались с URL.

**После:** URL содержит полный набор параметров: `page`, `spaceId`, `authorId`, `q`, `status` (список через запятую, если не все), `sortBy`, `sortDir`. Все фильтры сохраняются в URL. При загрузке страницы состояние восстанавливается из URL полностью. Кастомные селекты корректно отображают выбранные значения.
