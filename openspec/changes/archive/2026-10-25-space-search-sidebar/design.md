## Design

- **Controller**: `SpaceController` получает новый `GET /api/spaces/search` и возвращает список `SpaceResponse`.
- **Service**: `SpaceService` сначала собирает доступные пространства пользователя, затем фильтрует по названию и применяет пагинацию.
- **Repository**: `SpaceRepository` добавляет получение всех активных пространств без пагинации для сценариев поиска.
- **UI**: sidebar в `layout.html` содержит поле поиска и контейнер результатов; `main.js` переключает вид между деревом и результатами.

## Decisions

- Поиск выполняется по подстроке, без учета регистра.
- Если запрос пустой, sidebar возвращается к исходному дереву пространств.
- Если совпадений нет, отображается явное сообщение "Пространства не найдены".
