## Context

В настоящее время боковая панель приложения отображает плоский список пространств, полученный из `SpaceRepository`. Это не позволяет визуализировать вложенную структуру документов внутри каждого пространства, что затрудняет работу с большими базами знаний.

## Goals / Non-Goals

**Goals:**
- Реализовать отображение иерархии документов в боковой панели.
- Иерархия должна строиться в контексте выбранного пространства или глобально для всех пространств.
- Использовать рекурсивный компонент Thymeleaf для рендеринга дерева.

**Non-Goals:**
- Динамическая (AJAX) подгрузка дерева при развертывании узлов (в MVP достаточно статической генерации всей иерархии на сервере).

## Decisions

- **Сервисный слой:** В `DocumentService` будет добавлен метод `getSpaceDocumentHierarchy(Long spaceId)`, который будет извлекать все документы пространства и строить из них древовидную структуру (в памяти).
- **Контроллер:** `PageController` будет вызывать этот метод и передавать структуру `tree` в модель.
- **Представление (UI):** Использование рекурсивного фрагмента Thymeleaf (`th:replace`) для отрисовки вложенных `<ul>` и `<li>`.

## Risks / Trade-offs

- [Risk] → Потенциальная нагрузка на БД/память при очень большом количестве документов в пространстве. → Mitigation: В текущем MVP это приемлемо, при масштабировании потребуется кэширование или ленивая загрузка.
