# Spec: Экран просмотра истории версий (US2.2.2)

## Требования

### Требование 1: API истории версий документа
- Система должна предоставлять REST API эндпоинт для получения истории изменений выбранного документа.
- Для каждой версии в ответе должны содержаться:
  - дата и время изменения;
  - автор изменения (имя/email);
  - комментарий к коммиту (если присутствует).
- История должна загружаться строго для выбранного документа на основе пути файла в Git-репозитории.

### Требование 2: Интерфейс пользователя (Frontend)
- На странице просмотра документа должен присутствовать отдельный блок или боковая панель «История версий».
- Пользователь должен иметь возможность открыть данный раздел одним кликом.
- В разделе «История версий» отображается список всех версий документа с указанием даты, времени, автора и комментария к коммиту.
- Интерфейс должен гармонично вписываться в существующий дизайн приложения и использовать имеющиеся стили.

### Требование 3: Безопасность и проверка прав
- Доступ к истории версий документа должен быть ограничен правами пользователя на просмотр соответствующего пространства и документа.
