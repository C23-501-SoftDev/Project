## 3. Рефакторинг функции saveDocument()

- [ ] 3.1 Добавить параметр `options = { silent: boolean }` в `saveDocument()`
  - Если `silent === true`, не показывать toast при успехе
  - Используется для автосохранения

- [ ] 3.2 Добавить флаг `isSaving` для защиты от двойной отправки
  - При входе в `saveDocument()` проверять `if (isSaving) return;`
  - Устанавливать `isSaving = true` перед запросом, `isSaving = false` в `finally`

- [ ] 3.3 Реализовать обработку статуса 401 (Unauthorized)
  - В `catch` блоке проверять `if (error.status === 401)`
  - Выполнять `window.location.href = '/login';`
  - НЕ показывать toast перед редиректом

- [ ] 3.4 Реализовать обработку статуса 403 (Forbidden — CSRF)
  - В `catch` блоке проверять `if (error.status === 403)`
  - Показывать `showToast('Ошибка безопасности. Обновите страницу.', 'error')`
  - НЕ предпринимать повторных попыток

- [ ] 3.5 Реализовать обработку статуса 400 (Bad Request — валидация)
  - `apiFetch()` уже парсит `fieldErrors` и формирует `error.message` с их перечислением
  - Показывать `showToast(error.message, 'error')`

- [ ] 3.6 Интегрировать вызовы `updateAutosaveStatus(state)` в saveDocument()
  - Перед запросом: `updateAutosaveStatus('saving')`
  - При успехе (200 OK): `updateAutosaveStatus('saved')`
  - При любой ошибке (кроме 401): `updateAutosaveStatus('error')`

## 4. Автосохранение с debounce

- [ ] 4.1 Добавить переменные состояния в IIFE-замыкание
  - `let documentLoaded = false;`
  - `let autosaveTimer = null;`

- [ ] 4.2 Реализовать функцию `setupAutosave()`
  - Зарегистрировать обработчики `input` для `textarea` и `titleField`
  - При каждом событии `input`:
    - Проверить `if (!documentLoaded) return;`
    - Сбросить таймер: `clearTimeout(autosaveTimer);`
    - Обновить индикатор: `updateAutosaveStatus('unsaved');`
    - Запустить новый таймер: `autosaveTimer = setTimeout(() => saveDocument({ silent: true }), 3000);`

- [ ] 4.3 Вызвать `setupAutosave()` после успешного `loadDocument()`
  - В конце `loadDocument()` (после заполнения полей) установить `documentLoaded = true;`
  - Затем вызвать `setupAutosave();`

- [ ] 4.4 Сбросить таймер при ручном сохранении
  - В начале `saveDocument()` (до проверки `isSaving`) добавить: `clearTimeout(autosaveTimer);`
