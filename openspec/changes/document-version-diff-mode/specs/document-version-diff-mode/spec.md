## ADDED Requirements

### Requirement: Compare two registered document versions

Система MUST предоставлять пользователю с правом чтения документа результат сравнения двух различных Git-версий, зарегистрированных для этого же документа, в направлении от `from` к `to`.

#### Scenario: Successful comparison of selected versions

- **GIVEN** пользователь имеет право `READ` на документ и выбрал две различные версии из его истории
- **WHEN** клиент запрашивает `GET /api/documents/{id}/diff?from={fromHash}&to={toHash}`
- **THEN** система возвращает упорядоченные строки изменений именно файла этого документа
- **AND** каждая строка содержит тип изменения, текстовые сегменты и применимые номера строк до и после
- **AND** удалённые строки относятся к состоянию `from`, а добавленные — к состоянию `to`

#### Scenario: Version hash does not belong to document

- **WHEN** в запросе указан SHA, который не зарегистрирован для документа `{id}`
- **THEN** система возвращает `404 Not Found`
- **AND** не раскрывает содержимое или существование версии другого документа

#### Scenario: User has no document read access

- **WHEN** пользователь без права `READ` запрашивает сравнение версий документа
- **THEN** система возвращает `403 Forbidden`
- **AND** не выполняет чтение содержимого версий из Git

### Requirement: Render a GitHub-style visual diff

Страница истории MUST позволять выбрать две разные версии и отображать результат сравнения безопасно и наглядно.

#### Scenario: Highlight additions and removals

- **GIVEN** ответ сравнения содержит добавленные, удалённые и контекстные строки
- **WHEN** пользователь активирует сравнение выбранных версий
- **THEN** UI показывает удалённые строки красным с маркером `−`
- **AND** показывает добавленные строки зелёным с маркером `+`
- **AND** показывает контекстные строки в нейтральном стиле с номерами строк

#### Scenario: No textual changes

- **GIVEN** выбранные версии имеют одинаковое текстовое состояние документа
- **WHEN** сравнение успешно загружено
- **THEN** UI отображает явное сообщение, что версии не отличаются
- **AND** не показывает пустую или сломанную таблицу diff

#### Scenario: Document text contains HTML-like input

- **WHEN** строка документа содержит HTML или JavaScript-подобный текст
- **THEN** UI отображает его как текст diff-строки
- **AND** не исполняет и не интерпретирует этот текст как HTML

### Requirement: Select a text comparison algorithm

Система MUST позволять выбрать алгоритм `HYBRID`, `CHARACTER`, `WORD` или `LINE`; если алгоритм не указан, система MUST использовать `HYBRID`.

#### Scenario: Hybrid algorithm is selected by default

- **WHEN** пользователь открывает страницу истории или запрашивает diff без алгоритма
- **THEN** интерфейс показывает выбранный `HYBRID`
- **AND** сервер возвращает результат гибридного сравнения

#### Scenario: Character, word and line algorithms are selectable

- **WHEN** пользователь выбирает `CHARACTER`, `WORD` или `LINE` и запускает сравнение
- **THEN** система применяет выбранный алгоритм только к выбранной паре версий
- **AND** возвращает результат с сохранением безопасной структуры строк интерфейса

### Requirement: Highlight changed text within changed lines

Система MUST возвращать и отображать неизменённые, удалённые и добавленные сегменты текста внутри изменённых строк, чтобы автор мог увидеть точное место правки.

#### Scenario: Hybrid comparison of an edited line

- **WHEN** одна строка заменена строкой с частично совпадающим текстом и выбран `HYBRID`
- **THEN** общие фрагменты отображаются нейтрально
- **AND** удалённые символы отображаются как удаления, а добавленные — как добавления

#### Scenario: Inline view keeps additions and removals in reading order

- **WHEN** пользователь выбрал однопанельный режим
- **THEN** каждая изменённая строка показывает удалённые и добавленные сегменты последовательно в порядке diff

#### Scenario: Side-by-side view separates removals and additions

- **WHEN** пользователь выбрал двухпанельный режим
- **THEN** левая панель показывает только исходные строки и удалённые сегменты
- **AND** правая панель показывает только новые строки и добавленные сегменты
- **AND** совпадающие сегменты видны в обеих панелях нейтрально
