## ADDED Requirements

### Requirement: Compare two registered document versions

Система ДОЛЖНА предоставлять пользователю с правом чтения документа результат сравнения двух различных Git-версий, зарегистрированных для этого же документа, в направлении от `from` к `to`.

#### Scenario: Successful comparison of selected versions

- **GIVEN** пользователь имеет право `READ` на документ и выбрал две различные версии из его истории
- **WHEN** клиент запрашивает `GET /api/documents/{id}/diff?from={fromHash}&to={toHash}`
- **THEN** система возвращает упорядоченные строки изменений именно файла этого документа
- **AND** каждая строка содержит тип изменения, текст и применимые номера строк до и после
- **AND** удалённые строки относятся к состоянию `from`, а добавленные — к состоянию `to`

#### Scenario: Version hash does not belong to document

- **WHEN** в запросе указан SHA, который не зарегистрирован для документа `{id}`
- **THEN** система возвращает `404 Not Found`
- **AND** не раскрывает содержимое или существование версии другого документа

#### Scenario: User has no document read access

- **WHEN** пользователь без права `READ` запрашивает сравнение версий документа
- **THEN** система возвращает `403 Forbidden`
- **AND** не выполняет чтение содержимого версий из Git

### Requirement: Render a GitHub-style visual diff

Страница истории ДОЛЖНА позволять выбрать две разные версии и отображать результат сравнения безопасно и наглядно.

#### Scenario: Highlight additions and removals

- **GIVEN** ответ сравнения содержит добавленные, удалённые и контекстные строки
- **WHEN** пользователь активирует сравнение выбранных версий
- **THEN** UI показывает удалённые строки красным с маркером `−`
- **AND** показывает добавленные строки зелёным с маркером `+`
- **AND** показывает контекстные строки в нейтральном стиле с номерами строк

#### Scenario: No textual changes

- **GIVEN** выбранные версии имеют одинаковое текстовое состояние документа
- **WHEN** сравнение успешно загружено
- **THEN** UI отображает явное сообщение, что версии не отличаются
- **AND** не показывает пустую или сломанную таблицу diff

#### Scenario: Document text contains HTML-like input

- **WHEN** строка документа содержит HTML или JavaScript-подобный текст
- **THEN** UI отображает его как текст diff-строки
- **AND** не исполняет и не интерпретирует этот текст как HTML
