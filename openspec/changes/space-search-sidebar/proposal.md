## Why

Пользователям нужен быстрый способ находить нужное рабочее пространство и переключаться между пространствами без прокрутки длинного списка в sidebar.

## What Changes

- Добавление пользовательского API для поиска пространств по названию в контексте текущего пользователя.
- Обновление sidebar на SSR-страницах: поле поиска, отображение результатов, сообщение при отсутствии совпадений.
- Сохранение существующего дерева пространств как default-view при пустом поиске.

## Capabilities

### New Capabilities
- `space-search-sidebar`: Поиск рабочих пространств по названию и быстрый переход к найденному пространству.

### Modified Capabilities
- `space-management`: Расширение механизма получения пространств для пользователя.

## Impact

- **API**: новый эндпоинт `GET /api/spaces/search?q=...`.
- **Application**: `SpaceService` получает логику поиска по названию и пагинации.
- **UI**: `layout.html`, `main.js`, `main.css` обновляют sidebar.
