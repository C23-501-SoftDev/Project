# Bundled PDF fonts

Noto Sans regular/bold/italic/bold italic and Noto Sans Mono regular/bold.
Upstream: https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf
License: SIL Open Font License 1.1, see LICENSE. Exact URLs, SHA-256 checksums and sizes are in provenance.json.

Registered from classpath streams and subset-embedded by OpenHTMLtoPDF. Cyrillic and Latin coverage is tested; full Unicode/emoji coverage is not promised. Do not replace fonts without updating provenance and running MarkdownPdfFontTest.
