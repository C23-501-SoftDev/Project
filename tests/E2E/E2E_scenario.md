# E2E-сценарии тестирования

Документ описывает все автоматизированные сценарии из каталога `Project/tests/E2E/tests/`.  
Приложение — база знаний с SSR-страницами, REST API и админ-панелью.

**Окружение:** backend на `http://localhost:8081`, браузер Chromium, тестовый администратор `admin` / `admin123`.

---

## Наборы прогонов

| Команда | Что включает |
|---------|--------------|
| `npm test` | Базовый прогон: все spec-файлы без фильтра по тегам |
| `npm run test:strict` | Строгая приёмка (`@strict`) — без поблажек на заглушки |
| `npm run test:documents` | Документы (`@documents`) |
| `npm run test:userfull` | Полное пользовательское покрытие (`@userfull`) |
| `npm run test:filters` | Комбинации фильтров (`filter-combinations.spec.js`) |
